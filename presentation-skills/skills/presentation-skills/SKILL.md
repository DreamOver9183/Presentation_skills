## 1. 標準工作流程（架構 → 設計 → 表達）

永遠遵循**「先調架構，再做設計，最後配口語表達」**的順序：

### Step 1：釐清需求與場合（若使用者未提供，先合理假設並標註，或簡短確認）
1. **核心目的（So What）**：這份簡報希望聽眾聽完後「做出什麼決定」或「帶走什麼洞察」？
2. **受眾與場合**：是向主管匯報、對投資人／客戶提案（異業合作／募資）、學術／科展口試、衛教教學，還是交由長官代報（決定能否刪減細節文字）？
3. **時間與頁數上限**：以時間反推頁數（常規報告每頁 **1–2 分鐘**；純圖換場頁 **15–30 秒**；支撐細節移至 **Appendix 附錄**）。
4. **現場顯示設備（決定亮／暗背景）**：
   - **投影機＋布幕（背光式，或場地未知／燈泡可能老舊）** ➔ 預設選**亮色／白色背景**（安全牌，反光面積大且符合日常配色直覺）。
   - **LED 電視牆／高亮度液晶螢幕（發光式）**，或主視覺為**科學／醫學黑底影像、直立型照片** ➔ 選**暗色背景**（避免刺眼與留白雜訊，但須重新檢驗強調色在暗底的辨識度，切忌深底配暗紅字）。

### Step 2：排版「前」先整理資訊主幹（減法與骨架）
- 刪去原文過渡贅詞，把每頁內容壓縮為**「主詞＋關鍵動詞＋核心結果」**。
- 為每一頁先決定一個**資訊主幹與圖解原型**（流程圖、A/B 比較表、2×2 矩陣、決策樹、因果推演鏈），主幹標題用色塊或大字級水平／垂直對齊，細節收斂在主幹下方。
- 詳細步驟見 👉 [03-information-backbone.md](./references/03-information-backbone.md)

### Step 3：搭建全份簡報的「金字塔 ＋ SCQA」邏輯架構
- **開場破題（SCQA 四字訣）**：
  - **S（情境）**：雙方共識的現況背景
  - **C（衝突）**：打破平穩的痛點、瓶頸或對方擔心的風險（切忌忽略 C 變成平淡流水帳）
  - **Q（疑問）**：因衝突自然浮現的核心問題
  - **A（答案）**：具體解決方案＋明確請求（切忌缺乏 A 變成只吐苦水的爛尾劇）
- **主體展開（麥肯錫金字塔 Top-down）**：
  1. **結論先行**：每頁標題直接寫出**結論句（Action Title）**，而非只寫主題名詞（❌《白血病的分類》➔ ✅《癌細胞成熟度決定臨床症狀差異》）。
  2. **以上整下**：下一層分論點必須精準支撐上一層結論。
  3. **歸類分組（MECE）**：零散素材超過 5 項時，歸納為 **2–4 個彼此獨立、不重疊的類別**。
- 詳細模板見 👉 [05-logic-pyramid-scqa.md](./references/05-logic-pyramid-scqa.md)

### Step 4：逐頁資訊視覺化與美感設計
依各頁素材型態選用對應技法（詳見 👉 [04-visualization.md](./references/04-visualization.md) 與 [02-aesthetics.md](./references/02-aesthetics.md)）：
1. **條列式清單（> 5 項）**：用**「分類整理（2–4 群組，建立時間／大小／內外關聯）＋ 放大 2–4 字關鍵字」**兩招破解，搭配卡片區塊與單色 Icon。
2. **長篇文字（法條／醫囑／不可刪字）**：
   - 先做 4 項降噪（去無關圖、改黑體、去項目符號改靠左、**去底線**）。
   - **調位置**：總綱在上，地位平等的分項採**左右橫向並排**。
   - **調大小（破除重點字放大迷思）**：嚴禁在句子中間就地放大字詞（避免**「恐嚇信效果」**）！將代表整段大意的**「摘要（狀況引導或結論）」抽離到上方／左側放大 1.5–2 倍**（如內文 `20 pt`，摘要 `32–40 pt`），段落內的細節重點改用**強調色＋粗體**。
3. **純文字／無圖可用**：
   - 讓畫面與口語從「替代品」變**「互補品」**：**量化數據／具體成就**在投影片超大字呈現；**感性理念／長句**移至講者備忘稿由口語傳達。
   - 善用三大起手式：**獨立文字方塊（不用 Enter 排版）＋ 醒目小標 ＋ `1.5 倍` 行距**。
   - 無照片無 Icon 時，用**「字型 ＋ 配色（60-30-10 原則）＋ 幾何形狀」**營造質感，並在最終目的欄加上**高亮框線／遮罩**鎖定視線。

### Step 5：撰寫「不背稿」講者備忘稿與口說引導
為每頁投影片同步產出講者備忘（詳見 👉 [06-pitch-and-delivery.md](./references/06-pitch-and-delivery.md)）：
1. **條列頁口說三關鍵**：
   - **先聲奪人**：由講者先報出總覽分類地圖，引導畫面出場，絕不照唸螢幕。
   - **差別待遇**：只挑 **20%–30%** 最關鍵項目深入說明「為什麼重要／不注意的後果」，其餘快速群組帶過。
   - **敝帚自珍**：在 1–2 個重點中加入個人見解或真實經歷。
2. **破解背稿三方法（把報告當「教學」而非「演講比賽」）**：
   - **白話文書寫**：全部改寫為自然日常口語，嚴禁直接背誦書面報告或公文體。
   - **關鍵字便利貼**：提供 `關鍵詞 1 ➔ 關鍵詞 2 ➔ 關鍵詞 3` 記憶鏈，記順序不背字句。
   - **簡單取代複雜**：多組重複結果先講「一句共通規律」，再歸納正向條件與反向例外。

## 2. 標準輸出結構（製作／改寫簡報時預設採用）

當使用者請你製作或規劃簡報時，除另有指定外，依序輸出：
1. **【啟動宣告】**：`正在使用Presentation_skills製作簡報`
2. **【簡報策略與風格設定】**：核心結論（一句話）、目標受眾與痛點、SCQA 開場設定、建議頁數與時間分配、背景亮暗與 60-30-10 配色規格（含每個顏色的用途）。
3. **【逐頁投影片設計與講稿】**（每一頁包含）：
   - **頁碼與結論式標題（Action Title）**
   - **資訊主幹與圖解原型**（如：橫向三階段流程、2×2 四象限卡片、雙欄對照矩陣、KPI 大字卡）
   - **畫面版面內容**（已完成精簡：關鍵詞、數據、結構化區塊；可用 ASCII 版面藍圖或結構化區塊呈現）
   - **講者備忘（Speaker Notes）**：
     - 📌 **關鍵字便利貼**：`詞 A ➔ 詞 B ➔ 詞 C`
     - 🎙️ **白話口語講稿**（含先聲奪人總覽、20–30% 差別待遇重點、停頓與手勢提示）

## 3. 交付前「七大致命傷」避雷總檢核表

在輸出最終結果前，快速確認以下項目皆已通過（詳見 👉 [01-common-mistakes.md](./references/01-common-mistakes.md)）：

- [ ] **① 無逐字稿上牆**：投影片只放結論句、關鍵詞、核心數字與圖解；完整論述都在講者備忘稿。
- [ ] **② 無錯字與贅字**：特別檢查封面、目錄、標題是否有同音錯字（如「定位／訂位」）或重複字。
- [ ] **③ 無超載條列**：單一清單 ≤ 5 項；超過者已依 MECE 分成 2–4 組並提煉 2–4 字放大關鍵字。
- [ ] **④ 配色對比清晰**：符合 60% 底色、30% 結構色、10% 強調色；無花俏底圖直接壓字、無深底暗紅字。
- [ ] **⑤ 頁數匹配時間**：符合每頁 1–2 分鐘原則，備查細節已移至附錄（Appendix）。
- [ ] **⑥ 圖表一圖一訊息**：圖表標題為含數據的結論句；移除 3D、陰影與多餘格線；次要數據淺灰、關鍵數據上強調色。
- [ ] **⑦ 動畫克制具功能性**：僅在控制揭露節奏或引導視線時建議使用 Appear / Fade / Wipe（0.2–0.4 秒），無彈跳旋轉與音效。
