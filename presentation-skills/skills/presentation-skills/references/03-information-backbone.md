# 簡報排版前—整理資訊主幹

> 何時讀這份：在打開簡報軟體或決定版面配置「之前」，用來梳理複雜資料的邏輯架構、選出對應的圖解原型，並建立版面基礎格局。
> 出處：施金波《04 簡報技巧》Slide 9（及對應影片：簡報藝術烘焙坊 SlideArt〈排版簡報前，你該事先做好的一項功課〉，整理自設計師 Richard 林伯儒實務心得）

---

## 1. 核心觀念：為什麼排版前要先整理「資訊主幹」？

### 1.1 排版的本質難題與誤區
- **痛點**：簡報排版的狀況千變萬化，不易歸納出單一萬用通則。
- **常見誤區**：病急亂投醫——盲目下載免費模板，或惡補「你一定要知道的 99 種簡報排版技巧」，望著空白版面仍不知從何下手。
- **根本解法**：**先把電腦擺在一邊**，在打開軟體排版「前」（原投影片標題特別將「前」字以鮮紅粗體放大強調），先做好一項核心功課：**整理資訊主幹**。

### 1.2 什麼是「資訊主幹」？
- **定義**：在講解複雜資料時，用來承載與表達內容的**底層邏輯架構**，就是「資訊主幹」。
- **常見資訊主幹舉例**：
  - **三階段的流程**（先後順序／因果推進）
  - **兩種事物的比較**（A vs. B 對照）
  - **五乘五（5×5）的表格／矩陣分析**（多維度交叉比對）

---

## 2. 整理資訊主幹的三步驟操作法

### 步驟一：判讀原始資料的邏輯架構
逐段閱讀原始素材，抽離表面細節詞彙，找出各區塊之間的真實邏輯關係。
- **實戰案例（黃菁馨醫師：療法安全性研究簡報）**：
  - 第一部分：提及病患的症狀 ➔ 歸納為**「研究的對象與資料來源」**
  - 第二部分：描述療法使用的方式、儀器與參數設定 ➔ 歸納為**「研究的方法」**
  - 第三部分：不同副作用的追蹤與分析 ➔ 歸納為**「結果的分析討論」**
  - **判讀結論**：這是一套具明確先後順序的**「三階段流程」**（對象資料來源 → 研究方法 → 結果分析討論），也是科學／研究議題最常見的標準結構。

### 步驟二：依主幹挑選對應的「圖解原型」
- **核心原則**：優先針對資訊主幹做設計。這一步**幾乎不需要依賴美感或設計天分**，只要依資料架構選擇對應的「圖解原型（Diagram Prototype）」即可：
  - 互為先後「流程」關係 ➔ 選用**流程圖**（橫向或縱向階段＋箭頭）
  - 互為「對照／優劣」關係 ➔ 選用**雙欄比較表**
  - 互為「多維度交叉」關係 ➔ 選用**表格／矩陣**
  - 互為「條件推導與分支」關係 ➔ 選用**決策樹**（見練習 1）
- **簡化執行技巧**：不必拘泥於正統工程流程圖的嚴格符號格式。只要先寫出三大階段名稱，彼此以箭頭連接，就完成一個「簡化版的流程圖」。

### 步驟三：以主幹為基礎格局，填入細節（「添血添肉」）
- 將資訊主幹（例如橫向排列、水平對齊並以醒目色塊突顯的三個階段標題）直接作為投影片的**版面基礎骨架**。
- 剩下的細節文字，直覺地以「補充說明」形式，分別擺放到對應的階段小標題下方。

---

## 3. 先完成資訊主幹的兩大核心效益

### 效益一：提供後續排版的切入點（消除空白頁茫然感）
- 資訊主幹本身就是排版的基礎格局。
- 一旦基礎格局（如橫向三欄流程）確立，後續細節要放哪裡就毫無懸念，徹底消除望著空白投影片不知如何下手的困擾。
- **關鍵觀察**：此時決定頁面成敗的**不是**顏色、微調對齊、留白比例或字級等末節，而是**「資訊主幹本身是否極度清晰」**（例如每個階段標題用色塊凸顯並水平對齊，一眼提醒觀眾這是三階段流程）。

### 效益二：讓觀眾「快速秒懂」（喚起既有圖表認知）
- **「秒懂」的真正定義**：不是指觀眾一瞬間讀完所有細節文字，而是**在第一時間快速理解整張投影片的資料架構**——白話文就是：「**我知道這張圖大概在幹嘛**」。
- **認知心理機制**：原始投影片就算加了引導箭頭，若版面散亂，觀眾仍需費力判讀；當以「資訊主幹」將版面排得與觀眾過往經驗極度熟悉的圖表（如標準流程圖、對照表）高度相似時，能直接喚起觀眾對架構的熟悉感與判斷力，大幅加快理解速度。

## 4. 給 Agent 的排版前執行準則

當收到使用者的一段長文、報告或零散素材，準備轉換為投影片時：
1. **禁止直接分段貼上投影片**：先去除口語連接詞（「接著就是…」、「到這時，也該…」、「不妨…」），只抽取出「階段／類別 → 核心動詞與考量因素 → 決策規則」。
2. **先宣告本頁的資訊主幹與圖解原型**：
   - 屬於 N 階段流程 ➔ 橫向 N 欄流程卡片（搭配箭頭）
   - 屬於條件判斷 ➔ 決策樹（`├─ 條件 A ➔ 行動 1` / `└─ 條件 B ➔ 行動 2`）
   - 屬於多維度比較 ➔ 對照矩陣／表格
3. **主幹標題醒目對齊**：讓主幹標題在視覺上最突出、彼此水平或垂直對齊，細節統一收斂在各主幹區塊下方。

## 快速檢核

- [ ] 開始設計版面之前，已先用一句話界定本頁的「資訊主幹」（例如：三階段流程、A/B 雙向比較、2×2 矩陣、決策樹）。
- [ ] 已刪除原文中的過渡贅詞與口語連接詞，只保留「階段／維度 → 關鍵考量 → 結論／行動」骨架。
- [ ] 所選用的「圖解原型」與資料本身的邏輯關係一致，且符合觀眾日常熟悉的圖表形式。
- [ ] 主幹的各階段／類別標題在版面上已用色塊或字級明確凸顯，並保持對齊。
- [ ] 細節說明已歸位到對應的主幹標題下方，沒有游離在版面外的孤立文字塊。
- [ ] 觀眾掃視第一眼（1–3 秒內）就能說出「這張投影片大概在幹嘛」（秒懂資料架構）。
