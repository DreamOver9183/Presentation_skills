# 說出重點：講重點的方法、麥肯錫金字塔、條列口說與 SCQA

> 何時讀這份：要替使用者規劃簡報/報告的說話架構、撰寫講者備忘稿或口說稿，或使用者抱怨「講話沒重點、像流水帳、條列頁講得很無聊、不知道怎麼跟主管報告」時。

## 1. 講話沒重點的三大成因與解方（Slide 23）

講話沒重點、詞不達意，會直接影響職場升遷與影響力。根源歸納為三個：**過度緊張、詞彙太少、跳躍思考**。

### 成因一：過度緊張 → 五個解方
現象：面對主管或上台時壓力大，腦中一片空白，準備好的重點全忘光。

1. **充分準備**：上台前一定做足功課與資料整理；沒準備就上台必定緊張語塞。
2. **不斷練習**：「練習的次數，決定熟練的程度。」再資深的講者上場前都還是反覆練習。
3. **心靈預演（視覺化）**：找安靜空間閉眼，一幕一幕預演「上台前幾分鐘 → 走上台 → 與觀眾互動（點頭微笑）→ 結束後 Q&A 從容回答」。「想像得愈逼真，夢想就愈容易成真。」
4. **放鬆肢體**：身體僵硬會讓思緒跟著僵硬；上台前動動肩膀、轉轉脖子、晃晃身軀。
5. **深度呼吸「1：4：2 法則」**：腹式呼吸（氣沉下腹，不只停在胸腔），以 3 秒為單位 → **吸氣 3 秒、憋氣 12 秒、慢吐 6 秒**。憋不到 12 秒可循序漸進（例如吸 2 秒、憋 6～8 秒、吐 4 秒），身體適應後再拉長到 3–12–6。

### 成因二：詞彙太少 → 三個擴充詞庫策略
金句：「你的文字有限，你的影響力就有限。」不是沒想法，而是沒有精準詞彙可用，講出來東拼西湊。

1. **廣泛閱讀**：不只讀本業專業書，也讀美學設計、人文散文、歷史、人物傳記等跨領域書籍。
2. **在關鍵場合練習精準用字**：例如向長輩道歉，「不好意思我講錯話」顯得敷衍；改成「一時失言、有失公允，造成困擾深感抱歉，請您寬宏大量、多多海涵」，誠意與氣度立刻不同。
3. **向高手取經並複誦**：聽到主管、前輩、節目中的漂亮句子立刻筆記或拍照，利用通勤等零碎時間反覆唸誦。三階段：**先記憶 → 內化成創意 → 關鍵時刻靈活反應**。

### 成因三：跳躍思考 → 開口前用紙筆列三要素
現象：A 講一半跳到 C、再插敘 B，聽者跟不上，覺得「講很多卻沒重點」。
解方：無論事前準備或正在談話中被問到大問題，**不要憑感覺立刻開口**，先花幾秒在紙上列清楚：

1. **先後順序**：事情怎麼一步步發生（1、2、3）？
2. **前因後果**：什麼前提導致今天的狀況？
3. **輕重緩急**：哪一個最重要、最先要拍板？

### Agent 應用
- 撰寫任何講稿前，先替使用者把素材整理成「先後順序／前因後果／輕重緩急」三欄，再決定講述順序。
- 使用者表示緊張時，依序給五個解方，並把 1：4：2 呼吸法寫進「上台前準備」清單。

## 2. 麥肯錫金字塔表達術（Slide 24）

### 總前提
**把最重要的放最前面，次要的細節放後面（Top-down，由上而下）。** 主管與聽眾的大腦頻寬有限，需要先知道答案，再決定要不要追問細節。

### 三大原則
1. **結論先行**：第一句話就說出「最終結論」或「你希望對方做的決定」。
2. **以上整下、相關呼應**：上一層結論必須能總括下一層所有分論點；每個分論點都要精準支撐上層結論，不能離題或互不相關。
3. **歸類分組、論點獨立**：素材有五六七八項時，先把性質相近的歸成幾類，各類彼此獨立、不重疊。
   - 生活例「買菜清單」：高麗菜、青江菜、蘋果、香蕉、豬五花、雞腿肉——一項項唸容易漏；分成「蔬菜類／水果類／肉類」三類再展開細項，一秒就清楚。

### 操作步驟（寫報告或口說稿時）
1. 寫下一句話結論（或要對方做的決定）。
2. 列出所有原因、事實、困難（先不管順序，可用白板/便利貼）。
3. 把它們歸類成約三個彼此獨立的類別，每類取一個名稱當分論點。
4. 檢查每個分論點是否都支撐結論；不支撐的刪掉或移走。
5. 口說時先講結論；對方追問「為什麼？」再依分論點「第一、第二、第三」展開；最後可再收一次結論。

### Before / After 範例

**案例 A：電話報備會議改期**
- NG：「今天下午兩點半的會議喔，因為客戶早上打電話說臨時有事，加上一點半 Leo 要來拍片，然後會議室也被別組訂走了，而且……」→ 老闆打斷：「所以你到底是要我改到星期五嗎？！」
- OK：第一句「老闆，今天的會議必須改到星期五。」若老闆同意，一句話結束；若追問為什麼，再說「原因有三個：第一，客戶臨時有事無法出席；第二，同事拍攝時間要調整；第三，原本的會議室無法預約。所以建議順延至本週五。」

**案例 B：Hazel 匯報 Q3 進度**
- NG：從「拍攝計畫一直改、外包字幕很慢、Doris 幫忙改錯字、電腦當機、Leo 時間喬不攏、腳本重寫……」一路報流水帳 → 老闆：「停！先告訴我目標是多少、現在達成多少！」
- 整理：把七八件抱怨用便利貼歸成三類 ①拍攝計畫（流程）不明確 ②工作流程不完善（外包字幕/校對交接延遲）③硬體設備不夠好（剪輯電腦當機）。
- OK：「老闆，跟您報告 Q3 影片進度：**結論是目標 12 支，目前完成 8 支**。未達標原因主要有三項：第一，拍攝計畫不夠明確……；第二，工作流程不完善……；第三，硬體設備不夠好……。針對這三項，接下來我們已經規劃……」→ 老闆立刻知道卡在哪、該怎麼支援。

> 重點：做了很多事、碰到很多困難時，把過程完整報告反而讓主管覺得你在推託或沒重點。先講結論，過程歸類後再講。

### 金字塔口說模板
```
【結論/請求】＿＿＿＿（一句話：結果或希望對方做的決定）
【原因/論點】主要有三點：
  第一，＿＿＿＿（類別一，可附一個事實）
  第二，＿＿＿＿（類別二）
  第三，＿＿＿＿（類別三）
【收束/下一步】所以＿＿＿＿；接下來我們規劃＿＿＿＿。
```

## 3. 條列式簡報這樣講才有重點（Slide 26）

### 迷思
多數課程教「別念數據、用大圖少字說故事」，舉 Steve Jobs、TED 為例；但大師講的是理念與未來，一般人在學校職場報告的往往是**繁瑣的數據、文字、法條與表格**。關鍵仍在掌握簡報的「邏輯」與「目的」。

### 三大關鍵
1. **先聲奪人（引導邏輯）**：由「你」引導投影片內容出場，而不是看到畫面才照著唸、被內容牽著走。做法：先講總覽架構（分幾類、幾個面向），再讓內容逐塊出場（可搭配動畫）。
2. **差別待遇（聚焦目的）**：刻意挑出投影片上 **20%～30%** 的重點做進一步強調與解釋，其餘快速帶過；避免每點平均用力的流水帳。
3. **敝帚自珍（連結個人，加分項）**：針對重點中的一兩項，提出個人主觀見解或連結自己的故事經歷，能大幅加深印象。能否連結「可遇不可求」，有就大加分。

### NG 示範與常見誤區
- NG：「我知道時間很有限，所以我會盡量講快一點」→ 第一點、第二點、第三點……逐條照唸並重複字面意思（「確認場地燈光的配置，指的就是要確認燈光配置……」）。
- 誤區：察覺觀眾不耐煩時，以為是「內容太多」，於是**加快語速、不斷說「時間很趕」**——反而讓觀眾更不耐。問題在缺乏架構與重點，不在內容量。

### 正面示範：「上台前應檢查的 12 件事」
- **Step 1 先聲奪人**：「這 12 件事可分成『場地檢查』與『自我準備』兩大類」，再分四個面向：
  1. 場地檢查—觀眾區：燈光配置、投影幕範圍、投影機機況
  2. 場地檢查—講台區：講桌系統、外接筆電、音源與麥克風
  3. 自我準備—硬體類：自帶筆電、簡報筆、帶水
  4. 自我準備—軟體類：檔案備份、延伸螢幕操作、備案準備
  → 12 項在架構中快速交代完畢。
- **Step 2 差別待遇**：挑出新手最易忽略的 3 項（3/12＝25%）：確認投影機機況、測試音源與麥克風、預先配對簡報筆，並說明**為什麼**：這三樣往往是上台前才第一次碰到的設備，一旦凸槌，信心受打擊，讓準備許久的簡報功虧一簣。
- 效果：只是調整設計凸顯資訊架構、搭配動畫配合兩招，枯燥清單就「有重點又不無聊」；學術研討、醫學簡報同樣適用。

### 條列頁講者備忘稿模板
```
【總覽】這 N 項可以分成 ＿ 大類／＿ 個面向：A（…）、B（…）、C（…）。
【重點 20–30%】其中最關鍵的是 ＿、＿（挑約四分之一），因為＿＿＿＿（為什麼重要/後果）。
【個人連結（選用）】我自己就曾經＿＿＿＿／我認為＿＿＿＿。
【收束】以上 N 項 ＿ 大面向，就是＿＿＿＿。
```
Agent 撰稿規則：不要逐條改寫投影片文字當講稿；備忘稿只寫「架構句 + 重點的理由 + 選用的個人連結」。

## 4. SCQA 四字訣：用追劇邏輯告別流水帳（Slide 28）

SCQA 由麥肯錫顧問 Barbara Minto 在《金字塔原理》提出，用作溝通序言與邏輯骨幹。好報告像好看的劇：有起有伏、有衝突也有結局。

| 字母 | 意義 | 追劇類比（婚姻/家庭劇） |
|---|---|---|
| **S** Situation 情境 | 雙方都有共識的現況背景 | 全心為家庭奉獻的女主人、看似幸福的開局 |
| **C** Complication 衝突 | 打破平穩的轉折、麻煩、痛點 | 遇上不負責任／背叛的丈夫 |
| **Q** Question 問題 | 因衝突而自然浮現在聽者腦中的疑問 | 她該如何面對、維繫這個家庭？ |
| **A** Answer 答案 | 回應問題的核心結論、方案或行動主張 | 談判、專心做好媽媽、重新定義幸福，或果斷「休夫」 |

### 兩個職場範例

| | 情境一：專案卡關，向主管求支援 | 情境二：表現亮眼，主動爭取升職/帶人 |
|---|---|---|
| S | 團隊開發的新產品完成後預計為公司增加 30% 收益 | 我主導的產品線持續帶來超越預期的收益 |
| C | 但進入關鍵研發期，遇到棘手的技術瓶頸 | 但以目前較小的職責範圍，資源調度與影響力有限，已碰到天花板 |
| Q | 在卡關的條件下，怎麼做才能如期完成？ | 如何突破天花板、持續替公司提高收益？ |
| A | 我和工程師團隊已找到可行新解法，請主管在人力/資源上給予支持 | 我希望晉升並領導一個 5 人小組，加快後續產品開發 |

小技巧：工作順遂時最不會講 C——把「現有角色範圍限制了更大貢獻」設定為衝突即可。

### 兩大地雷
1. **忽略 C**：只報喜不報憂、只講平常做了什麼 → 沒有起伏的「平淡流水帳」，主管不懂你辛苦在哪、為何要幫你。
2. **缺乏 A**：只吐苦水講有多難，沒有分析後的解法或具體請求 → 主管最痛恨的「只有問題沒有解法的爛尾劇」。

### SCQA 填空模板
```
S 情境：目前＿＿＿＿（雙方都同意的事實/成果/目標）
C 衝突：但是＿＿＿＿（瓶頸、落差、限制、風險）
Q 問題：那我們該如何＿＿＿＿？（衝突引出的那個問題）
A 答案：我建議／我已經＿＿＿＿，需要您＿＿＿＿（具體方案 + 明確請求）
```
Agent 撰稿規則：寫完後檢查 C 是否真實具體、A 是否含「方案 + 請求」；任一缺漏就補問使用者。

## 快速檢核

- [ ] 開口前已用「先後順序／前因後果／輕重緩急」整理過素材，沒有 A→C→B 的跳躍
- [ ] 第一句話就是結論或希望對方做的決定（結論先行）
- [ ] 每個分論點都支撐上層結論，沒有離題項目（以上整下）
- [ ] 零散素材已歸成約三個彼此獨立、不重疊的類別（歸類分組）
- [ ] 條列頁先講總覽架構，由講者引導內容出場，而非照唸（先聲奪人）
- [ ] 只挑 20%～30% 重點深入說明並講出「為什麼」（差別待遇）
- [ ] 若有合適的個人見解或經歷，已連結到一兩個重點（敝帚自珍）
- [ ] 沒有「時間很趕、我講快一點」這類話，也不靠加快語速解決冗長
- [ ] 需要說服時用 SCQA：C 有具體衝突、A 有方案與明確請求
- [ ] 使用者若會緊張，已提供五個解方與 1：4：2 呼吸法（吸 3、憋 12、吐 6）
