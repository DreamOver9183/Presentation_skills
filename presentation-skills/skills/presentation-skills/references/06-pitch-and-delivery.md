> 何時讀這份：當使用者要準備商業提案（異業合作／募資 Pitch）、需要強化上台氣場與肢體語言，或想擺脫「死背逐字稿、上台像機器人照唸」的口頭報告困境時。

## 第一部分：提案力實戰（Slides 30–32｜《誰語爭鋒》EP.4）

即使沒有投影片輔助（純口語 3 分鐘電梯簡報／Pitch），提案能打動企業老闆與投資人的核心邏輯完全相同。

### 1. 提案的兩大類型與唯一勝出標準（Slide 30）
- **兩大提案場景**：
  1. **異業合作**：讓對方聽完覺得「我想跟這個人合作！」
  2. **募資／爭取資源**：讓對方聽完覺得「這個提案有打中我，我願意掏錢支持／贊助！」
- **核心鐵則——關聯度與換位思考**：
  - **「如果聽的人覺得這件事跟他無關，沒有人會接受這樣的提案。」**（陳宥彤導師）
  - **嚴禁把「合作／投資對象」當成「一般消費者」推銷**：
    - ❌ 反面案例：向企業老闆提案婚禮平台，卻一直在講「新人想要穿最漂亮的衣服、有身材困擾……」，被當場點破：「我覺得我變成被推銷產品的『客人』，完全沒感受到你在跟我『談合作』！」
    - ❌ 反面案例：上台要求企業老闆出錢贊助，卻只講自己有多缺錢、多辛苦，被嚴厲批評：「投資人想看的是**『我給你錢之後，對我有什麼好處（ROI／價值）？』**，不是聽你個人發洩！」

### 2. 用三層金字塔消除跳躍思考，帶聽眾「進入情境」（Slide 30）
- **為什麼寫稿會跳來跳去？** 初學者常在這一句寫「論點一」，下一句跳到「論點三」，第二段第一句又繞回「論點一」，東講一個、西講一個，聽眾完全無法跟上。
- **白板三層金字塔建構法**：
  1. **頂層｜主述（Core Message）**：涵蓋 `Who / What / Why + So What`（對聽眾有什麼價值）。
  2. **中層｜分論點（Arguments 1 / 2 / 3）**：彼此獨立、共同支撐主述。
  3. **底層｜證據（Evidence 1-1, 1-2…）**：具體數據、案例與執行做法。
- **目標**：用嚴密邏輯把聽眾一步一步帶進情境，自然推導出共同結論。

### 3. 提案最大的通病：對自己的產品／方案不了解（Slide 31）
> **「大家提案共同的問題就是：你們其實對『自己的產品不了解』、沒有在『打磨產品』。因為對產品不了解，所以你只能點出現有的問題，卻沒有告訴人家——你要怎麼去面對跟解決現有的問題！」** —— 陳宥彤導師

- **完美 3 分鐘提案的本質**：
  - 只點出問題（痛點）卻給不出具體可行的解決機制，是因為背後根本還沒把產品／方案打磨成熟。
  - **「把產品打磨完成之後，還能夠在 3 分鐘內好好地表達出來——這就是最完美的提案。」**
- **給 Agent 的提案撰稿守則**：幫使用者寫提案稿時，不能只寫熱血口號與市場痛點；若使用者還沒定義清楚**「具體解決方案、執行機制、商業模式／合作互利點（What's in it for them）」**，必須主動追問並幫他補齊。

### 4. 去公文化與舞台氣場、肢體語言（Slide 30 & Slide 32）

#### 4.1 內容面：戒除「公文感」，大膽展現個人與溫度（張敏敏老師）
- ❌ **忌像寫公文**：用詞過於迂迴、官腔、四平八穩（「如果在這樣的環境裡面，有了不同的人給予建議，也許在迂迴裡會得到清澈思路……」），聽起來不像真人說話。
- ✅ **大膽真誠**：面對大老闆或決策者，主張要直接、大膽；若是代表某個群體發聲（如偏鄉教師），要點出**「為什麼今天是由我站出來代表他們說話」**的使命感。
- ✅ **情緒渲染的「空白停頓」**：在情感或關鍵數據最觸動人心的時刻，刻意做出 **1–2 秒的「停頓（Pause）」**——不是哽咽，而是留給聽眾消化與產生共鳴的空白拍。

#### 4.2 肢體與設備面：撐出氣場、消除贅詞與晃動
- **問題診斷（「義肢晃動」與「水波浪」連動效應）**：
  - 許多講者（特別是年輕或緊張講者）**上手臂一直緊黏著上半身**，只有手腕以下像「義肢」一樣在空中無意義晃動。
  - 當肢體沒有打開固定時，身體會不自覺像「水波浪」左右搖晃，並連帶誘發口語出現大量**「所以呀、那因此呢、然後…」等贅詞與贅動作**，嚴重削弱說服力。
- **三大具體修正動作**：
  1. **上手臂離開上半身（撐出氣場）**：刻意將上手臂往外打開、離開軀幹，瞬間放大視覺氣場與自信度。
  2. **四指併攏、定點下切（展現手的力道）**：
     - 平時雙手**四指併攏**，穩定擺在胸前中軸定點位置；
     - 講到關鍵主張、需要強調重擊力道時，雙手同時乾淨俐落地做出**「往下切」**的手勢，最具專業權威感。
  3. **善用「耳麥」解放雙手**：
     - 條件允許時，優先選用**耳戴式麥克風（耳麥）**取代手持麥克風，才能徹底解放雙手做全方位互動（配戴耳麥時，需預先確認服裝／西裝口袋或褲頭能穩固夾住發射盒）。

## 第二部分：如何讓報告不像背稿？（Slide 33｜科學 X 博士）

### 1. 心態重定位：口頭報告不是「演講比賽」，而是「上課（教學）」

許多人準備報告的流程是「寫出書面逐字稿 → 死背下來 → 上台一字不漏急促唸完」，結果語調平直僵硬、一忘詞就卡死。根本原因在於把報告誤當成「演講比賽」。

| 比較維度 | 演講形式（Speech） | 上課／教學形式（Teaching —— **報告應採模式**） |
| :--- | :--- | :--- |
| **核心著重點** | 字句優美、修辭編排 | **先講什麼、再講什麼、哪裡不能漏、怎麼講聽眾才聽得懂** |
| **是否需逐字背誦** | 特定精雕細琢的金句需逐字背下（如：「就這樣，超過 2,000 條原本可能犧牲的寶貴生命，因此而獲救」） | **完全不需要執著哪個字非講不可**；重點在邏輯順序與讓聽眾理解 |
| **互動特性** | 單向輸出為主 | 聽眾（評審／主管／老師）**隨時有問題都可能打斷發問**的雙向溝通 |
| **終極目標** | 完成表演 | **讓沒有你熟悉這份內容的評審／聽眾「輕鬆聽懂」**（而非把稿唸完撐過時間） |

### 2. 破解背稿窘境的三大實戰方法

#### 方法一：白話文書寫——寫「給嘴巴說的稿」，不背「給眼睛讀的報告」
- **核心原則**：研究報告、企劃書上的文字是**書面語（給人讀的）**，直接拿去背誦必定生硬卡頓。若因緊張非寫稿不可，從動筆第一秒就要寫成**日常口語的白話文**。
- **Before / After 實戰對照（紙火箭降落傘實驗步驟）**：
  - ❌ **書面稿直接背誦（生硬機器人）**：
    > 「步驟一，將紙火箭降落傘組裝完成。步驟二，將紙火箭降落傘放入發射台。步驟三，將 PSI 值設定好，並且打開充氣電源開始充氣。步驟四，當打氣機停止打氣時，打開洩氣閥，並且開始計時。步驟五，紙火箭降落傘順利升空，展開傘面並且降落。步驟六，觀察並記錄實驗結果。」
  - ✅ **改寫為白話口語稿（自然順暢）**：
    > 「我們先把組好的紙火箭降落傘放入發射台，然後設定好 PSI 值，再讓打氣機開始充氣；充好氣之後，我們就打開洩氣閥、開始計時；再來紙火箭降落傘就會升空，然後打開降落傘降落；最後我們再把結果記錄下來。」

#### 方法二：關鍵字便利貼——記「順序與關鍵字」，用平常說話方式串接
- **核心原則**：大腦真正要記的不是「一字一句」，而是**「先講什麼 → 接什麼 → 後講什麼 → 哪些核心詞絕對不能漏」**。每個關鍵字背後的前後文，只要實驗／專案是你做的，你本來就不會忘記。
- **操作步驟**：
  1. 從白話文稿中挑出不可遺漏的**關鍵字**（例如：`組裝` → `發射台` → `設定 PSI` → `充氣` → `開洩氣閥＋計時` → `升空開傘` → `記錄結果`）。
  2. 把每個關鍵字寫在獨立便利貼（或講者備忘卡）上，排好先後順序。
  3. 上台時只看關鍵字順序，中間的連接詞與解釋**完全用自己平常講話的習慣自然說出**，徹底擺脫背稿感。

#### 方法三：簡單取代複雜——幫聽眾做「語言減負」，把腦力留給專業內容
- **核心原則**：評審或主管一定沒有你熟悉這個專案。若你逐條唸出未經整理的重複句式，聽眾除了要理解專業內容，還要額外耗費精神去拆解、歸納你的中文語句，聽起來就會極度吃力。**必須把「需要動腦筋才能理解的句子」，轉換成「不用動腦、一聽秒懂的結構化句子」。**
- **Before / After 實戰對照（降落傘六組變因實驗結果）**：
  - ❌ **未整理的逐條背誦（句式高度重複、資訊零散）**：
    > 「正方形和五邊形的飛行時間最長，正方形的穩定度最高。不同傘面面積：傘面 3,600 平方公分的飛行時間最久，穩定度也最高。不同傘面中心開洞大小：傘面中心開洞半徑兩公分的飛行時間最長，穩定度也最高。不同形狀支撐桿：不加支撐桿的降落傘飛行效果較佳，飛行時間最長。載體的重量：載體的重量愈輕，飛行的時間愈久，穩定度也愈高。探討降落傘拉繩的數量：拉繩的數量以四條的飛行時間最久，穩定度也最高。」
  - ✅ **簡單化重組（先立共通結論 → 歸類正向條件 → 點出反向例外）**：
    > 「在這個實驗中我們首先發現一個共通規律：**只要飛行時間最長，它的飛行穩定度也會最高**。那麼哪些條件能讓飛行時間最長、穩定度最高呢？整理起來有五項：形狀上是**正方形和五邊形**、面積是 **3,600 平方公分**、中心開洞是**半徑 2 公分**、**載重越輕**，以及**拉繩數量 4 條**。不過我們也同時發現一個例外：如果**增加了支撐桿**，飛行效果反而不會變好，飛行時間也不會變長。」

## 3. 給 Agent 的講稿／提案稿撰寫規範

當使用者請你撰寫「講稿、演講稿、口頭報告稿、提案稿或講者備忘（Speaker Notes）」時，預設同時提供兩層結構：
1. **【關鍵字便利貼序列】**：用 `關鍵詞 A ➔ 關鍵詞 B ➔ 關鍵詞 C` 列出每頁／每段的記憶錨點，供使用者上台掃視、不背稿自然發揮。
2. **【白話口語示範稿】**：
   - 嚴禁用書面公文體或直接複製報告原文；
   - 遇到多組重複結構的實驗結果或數據，主動幫使用者「先提煉共通結論，再歸納正向條件與反向例外」；
   - 在關鍵轉折或情感高點標註 `（停頓 1–2 秒）` 與手勢提示（如：`【手勢：四指併攏往下切】`）。

## 快速檢核

- [ ] **換位思考**：提案內容已明確回答「對合作方／投資人／決策者有什麼具體好處（So What）」，沒有把合作方當一般消費者推銷，也沒有只顧著吐苦水。
- [ ] **方案已打磨**：不只點出現有問題，更具體說明「如何面對與解決問題」的執行機制。
- [ ] **金字塔不跳躍**：段落邏輯嚴守「頂層主述 → 中層論點 → 底層證據」，沒有論點 1 跳論點 3 又跳回論點 1。
- [ ] **去公文化與停頓**：口語稿無官腔公文感；關鍵金句或情感渲染處已標註空白「停頓」。
- [ ] **肢體與氣場提醒**：若使用者需上台建議，已提醒「上手臂離開上半身、四指併攏置於胸前定點、強調時雙手往下切、減少水波浪晃動與口頭贅詞、優先使用耳麥」。
- [ ] **不背書面語**：講稿已全部轉譯為自然的「日常白話文」，不含「步驟一、將……進行……」等生硬書面語。
- [ ] **附關鍵字便利貼**：每段講稿皆附上濃縮的「關鍵字順序鏈」，讓講者記順序而非死背字句。
- [ ] **簡單取代複雜**：重複句式的實驗結果或多維度數據，已重組為「一句共通規律 ＋ 歸類條件 ＋ 例外轉折」，減輕聽眾大腦負擔。
