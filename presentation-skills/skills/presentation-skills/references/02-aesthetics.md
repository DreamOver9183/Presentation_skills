# 簡報美感：質感養成、雜誌風排版改造與亮暗背景決策

> 何時讀這份：當需要決定一份簡報的視覺風格、提升投影片質感、改造平淡的規格／資訊頁，或決定背景要用亮色還是暗色時參考。

## 1. 質感從哪裡來？——風格延伸三步驟（Slide 6）

### 1.1 質感的兩大來源

觀眾不需理解內容，就能憑直覺判斷兩張內容相同的投影片哪張較有質感。差異主要來自：

1. **整體性**：顏色的使用、字體選擇、線條與色塊細節彼此互相搭配，共同構成一致的風格。只有「模板既有配色統一」而沒有其他元素連動，就缺乏整體性。
2. **多數人做不到**：無論是技術上不會做，或想不到要這樣做，只要視覺呈現「不常見」，就會帶來「厲害、有質感」的感受。

**推論規則**：追求質感時，盡量避免簡報軟體的**預設模板、預設形狀、預設配色**——不是因為預設一定不好，而是「隨便點兩下就能做到」的東西不會讓人驚豔。

### 1.2 風格延伸（Style Extension）流程

從某個既有設計風格出發，延伸做出全新的投影片：**挑選參考 → 拆解分析 → 延伸仿作**。

#### 步驟一：挑選參考
- 世界上**沒有萬用的最佳風格**可以照抄；合適即可，沒有標準答案。
- 挑選依據：自己喜歡的簡報／設計作品，或依**簡報場合**選擇走向：
  - 兒童為主的場合 → 可愛插畫風、手繪風。
  - 商務場合 → 偏理性、專業的風格。
- 素材來源：Pinterest、Behance 等設計平台搜尋 "PowerPoint"；參考對象**不限於投影片**，UI 介面、海報等設計作品皆可。
- 影片範例：以 Denis Turanović 的「模擬 Tesla 儀表板」UI 作品為參考。

#### 步驟二：拆解分析（初學者鎖定四維度）

| 維度 | 要分析什麼 | Tesla UI 範例 |
|---|---|---|
| 配色 | 不只看用了哪些色，重點是**「色彩用途」**：每個顏色用在哪裡 | 藍／白／黑三色。黑＝大面積背景；白＝大部分文字；藍＝圖示（icon）與長度條 |
| 字型 | 字體類型與給人的感覺 | 無多餘裝飾的無襯線體（sans-serif）；想呈現科技感時通常是理想選擇 |
| 形狀 | 找出風格的**核心特徵形狀** | 兩條括弧形狀的灰色細線（核心特徵）；藍色粗線條可用於重點強化 |
| 排版 | 主體位置、主從關係 | 最大的主體直接置中；馬路影像調暗退居背景 |

> 「色彩用途」的拆解是後續仿作能否成立的關鍵。

#### 步驟三：延伸仿作（兩層練習）
1. **臨摹復刻**：從空白頁重現一張一模一樣的畫面，再用「大家來找碴」比對差距（字體風格像不像、文字大小比例是否不同）。常會發現原本忽略的細節（如藍色粗線其實帶有藍色光暈）——代表細節掌握度提升。
2. **替換內容**：把質感待加強的投影片，沿用步驟二拆出的設計元素重新改作；可進一步強化資訊視覺化（範例：改用類似**百分比堆疊橫條圖**的形式，凸顯三個數字之間的占比關係）。

**防崩壞守則**
- 對拆解出的元素**不要大幅修改**，否則風格容易崩壞、面目全非。
- 範例取捨：不必沿用所有元素（Richard 沒有大量沿用 icon 與長度條），只要做到 **(1) 統一字型與顏色（含色彩用途）＋ (2) 保留核心形狀（括弧細框線）**，風格就能與參考非常接近，並學會在同一風格下變化出不同版面。

**版權提醒**：風格延伸屬於個人私下練習；若把仿作直接當作品對外發布，可能被認定為抄襲。

### 1.3 給 agent 的應用方式
為一份簡報定風格時：
1. 依場合與受眾決定風格走向（理性專業 vs. 可愛手繪等）。
2. 明確定義「風格規格」：配色＋**每個顏色的用途**、字型、核心形狀元素、排版主從原則。
3. 全份投影片嚴格沿用這組規格（整體性），變化版面但不變動元素本身。
4. 避免直接套用軟體預設模板／形狀／配色。

## 2. 用時尚雜誌手法改造平淡資訊頁（Slide 7）

### 2.1 案例與情境
- 案例：電力傳輸產業客戶的**產品規格表**投影片。
- 規格表現場不會逐行唸，頂多提亮點，通常**不是簡報主角**——正因重要度低，適合實驗較少用的進階設計手法。
- 本案「絕口不提邏輯」，專注於**一個個微小的美感設計選擇如何堆疊成整體畫面**。

**原版問題（撇除模板）**
1. 藍色區塊內的規格文字只是純粹條列。
2. 產品照片制式、微小地擺在旁邊，版面空間沒被善用。

### 2.2 改造步驟（可移植的手法）

**A. 圖片：放大 → 貼邊出血 → 圖文交錯**
1. **換掉舊模板、把圖片放到超大**：圖小而空白多時，嘗試讓圖片佔據極大面積，由它主導整體設計方向（放大後，圖片位置對整體影響很大）。
2. **貼邊出血化解裁切缺陷**：原圖右上角已被裁切，單獨擺放顯得不完整 → 把圖貼齊投影片最右側邊界，營造「產品太長而超出邊界」的效果，彌補裁切。順勢把文字與另外兩張小示意圖放到左側，大格局定案。
3. **借鏡平面設計創造空間感**（解決大圖單調）：
   - 海報手法：擠在畫面邊緣的「變形小字」，反襯圖片的巨大尺度。
   - 時尚雜誌封面手法：**文字與圖片交錯重疊**，創造前後景空間感。
   - 實作：用**較細的字體**把產品名稱疊在產品大圖上。

**B. 文字：說明書式雙層級**
- 借鏡產品說明書，不平鋪直敘地條列，而是用**字體大小與粗細對比**拆成「子標題」與「內容」兩個層級。
- 例：子標題 `Type` 放大加粗，內容 `LA-LB series` 稍小；以同一規則重複套用，整理出 6 組規格。

**C. 局部圖解（挑合適的規格做資訊視覺化）**
- **數值範圍 → 漸層長條**：「電流需介於 400–6500 安培」改用類似長條圖＋漸層，暗示數值往右遞增，並示意區間內皆為可接受範圍。
- **冗長名稱 → 符號縮寫**：導體「銅、鋁」英文名稱較長，改用化學元素符號 Cu、Al 簡潔示意。

**D. 卡片式設計（解決層級混雜）**
- 問題：規格文字放回版面後，與右側大圖的視覺層級混在一起，沒有「自成一格」。
- 解法：用**白色圓角矩形**把規格框起來，加**淡淡的陰影**，形成網頁常見的卡片式設計（Card Design）。
- 讓白卡與右側產品大圖**適度交錯重疊**，搭配陰影的浮起感，使前後空間關係更明確、版面更有層次。

### 2.3 核心體悟
- 前後版本資訊量相近，但「放大貼邊＋雜誌字圖交錯＋說明書雙層文字＋漸層長條與縮寫圖解＋圓角白卡淡陰影」一個個微小選擇累積後，質感差距巨大。作品視覺好不好，很大程度取決於這些選擇。
- 這套手法屬於**排版與空間層次**，即使整套換配色仍然適用。
- 靈感可跨領域借用：海報、雜誌封面、產品說明書、網頁卡片設計。

## 3. 背景該選亮色還是暗色？（Slide 8）

### 3.1 定義與盲點
- **亮色背景**：亮色為底、深色元素（白底黑字）。
- **暗色背景**：暗色為底、淺亮色元素（黑底白字）。
- 常見直覺：「亮色才有活力、不死氣沉沉」vs.「深色才專業（如 Apple 等電子公司發表會）」。兩者都有道理，但共同盲點是**靠感覺決策**。決定前必須評估三大實務關鍵：**器材、圖片、配色**。

### 3.2 關鍵一：器材

| 投影類型 | 常見場域／設備 | 成像原理 | 實務風險 | 建議背景 |
|---|---|---|---|---|
| 背光式（投影機＋布幕） | 一般會議室、教育訓練場地、學校、公家機關 | 布幕本身不發光，只反射投影機光源 | 燈泡老舊、亮度衰減時畫面昏暗看不清 | **亮色背景**：增加發光／反光面積；用暗色背景會讓老舊燈泡毫無威力 |
| 發光式（LED 電視牆、液晶螢幕） | 產品發表會、高級會議室 | 螢幕本身就是光源，直接把影像打進觀眾眼中 | 刺眼、視覺壓迫 | **暗色背景**：降低整體亮度，聚焦內容 |

> Apple 等發表會採深色背景，除了專業感，更實務的原因是現場使用高亮度 LED 牆，不希望大面積亮白讓觀眾刺眼，同時讓視線集中在產品上。

### 3.3 關鍵二：圖片
原則上圖片「滿版出血、越大越好」，但無法 100% 滿版時，露出的背景會影響觀看：

1. **科學或醫學影像**（深黑底＋染劑或發光標示的彩色重點）：白色背景會成為「更強、更亮、更搶眼的雜訊」→ **改用暗色背景**。在電腦小螢幕上黑邊或許不好看，但投影到大螢幕時觀眾不會注意暗掉的邊緣，視線能專注於影像重點。
2. **直立型照片／圖片**：硬做橫式滿版會大幅裁切、構圖所剩無幾或畫質受損；置中放置時，兩側留白會不斷提醒觀眾「圖沒滿版」→ **背景改深色**，讓兩側退隱、聚焦中央主體。
3. **圖文交錯型投影片**：最忌諱「投影片背景色」與「圖片自身底色」不一致，會產生色差與不自然邊界。
   - 除非願意把圖片去背得非常乾淨，否則採**設計遷就素材**：投影片背景色配合多數主要圖片的底色。
   - 反之，若已先定好背景色，選圖時盡量挑底色相符的圖片。

### 3.4 關鍵三：配色
- **亮底的配色直覺不能直接搬到暗底**。經典反例：白底習慣用紅色標重點（源自老師紅筆批改、重要印章用紅色），但在黑／深色背景上，紅色的辨識度甚至不如白色；投影機燈泡老化、亮度不足時，深底紅字更是晦暗不清。
- **規則反轉**：許多在亮底顯得模糊的顏色，在暗底反而是極佳強調色；反之亦然。
- **時間不足時的安全牌**：若無暇鑽研色彩學，選**亮色／白色背景**較易成功——日常文件、印刷品、海報多為白底，人們早已內化白底的配色直覺，可直接沿用、降低失敗風險。

### 3.5 背景決策流程（依序三問）
1. **器材**：現場是發光式（LED／電視）還是背光式（投影機＋布幕）？亮度會過亮刺眼，還是老舊過暗？
   - 投影機／老舊燈泡 → 傾向亮色；LED 牆／高亮螢幕 → 傾向暗色。
2. **圖片**：是否有科學／醫學影像、直立型圖片，或要做圖文交錯版面？
   - 科學醫學影像、直立圖 → 傾向暗色；圖文交錯 → 背景色跟隨主要圖片底色。
3. **配色**：若沒有特別心思處理深底配色邏輯 → 優先選白色背景。
   - 若選暗色背景 → 逐一重新驗證強調色（尤其紅色）在暗底與低亮度投影下的可辨識度。

## 快速檢核

- [ ] 全份投影片有明確且一致的風格規格：配色（含每個顏色的用途）、字型、核心形狀元素、排版主從原則。
- [ ] 顏色、字體、線條、色塊互相搭配，不只是「模板配色統一」。
- [ ] 沒有直接沿用軟體預設模板、預設形狀、預設配色。
- [ ] 風格走向符合場合與受眾（商務→理性專業；兒童→插畫／手繪等）。
- [ ] 若參考既有風格，只沿用拆解出的元素且未大幅變形；對外作品沒有直接複製他人設計（避免抄襲）。
- [ ] 重要圖片已考慮放大到主導版面；被裁切的圖已用貼邊出血處理，不孤立擺放顯得不完整。
- [ ] 平淡的資訊頁已嘗試空間層次手法（細字與大圖交錯重疊、邊緣小字反襯大圖等）。
- [ ] 規格類文字已用大小／粗細拆成「子標題＋內容」兩層級，而非純條列。
- [ ] 適合圖解的資訊已視覺化（數值範圍→漸層長條；冗長名稱→符號縮寫；占比→百分比堆疊橫條）。
- [ ] 文字區與大圖層級混雜時，已用卡片（圓角底框＋淡陰影）區隔並營造前後景。
- [ ] 背景亮暗是依「器材 → 圖片 → 配色」三問決定，而非憑感覺。
- [ ] 投影機＋布幕（尤其燈泡老舊）場地用亮色背景；LED 牆／高亮螢幕場地用暗色背景。
- [ ] 科學／醫學影像、直立型圖片的頁面，背景已調暗以免留白成為雜訊。
- [ ] 圖文交錯頁的投影片背景色與圖片底色一致（或圖片已乾淨去背），無色差邊界。
- [ ] 暗色背景上沒有直接沿用白底配色習慣（如深底紅字），強調色已在暗底與低亮度條件下驗證可辨識。
- [ ] 不確定配色能力或場地條件時，已選用白色／亮色背景作為安全牌。
