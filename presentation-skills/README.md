# Presentation_skills

本插件萃取自施金波《04 簡報技巧》完整報告，提供：
- **`presentation-skills` Skill**：涵蓋簡報常犯七大錯誤避雷、美感訓練三步驟、亮暗背景決策、排版前整理資訊主幹、資訊視覺化六大技法、麥肯錫金字塔原理、SCQA 四字訣、提案力實戰與不背稿自然表達心法，以及 8 道課堂練習的完整示範解法。
- **常駐觸發規則（`rules/AGENTS.md`）**：當處理任何簡報、投影片、PPT、大綱、提案或講稿相關任務時，自動啟用 `presentation-skills` 並在開頭顯示「`正在使用Presentation_skills製作簡報`」。
